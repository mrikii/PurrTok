# 🐱 PurrTok — твой пушистый антистресс-помощник

**PurrTok** — интерактивный Telegram-бот для борьбы со стрессом, эмоциональным выгоранием и думскроллингом. Мы объединили возможности искусственного интеллекта, игровые механики и атмосферу кошачьего уюта, чтобы создать доступный инструмент психологической разгрузки, который всегда под рукой.

Наша цель — помочь человеку ненадолго отвлечься от повседневных забот, выразить эмоции, восстановить силы и улучшить настроение.

---

## 💡 Идея проекта

Современный человек проводит значительную часть жизни перед экраном: учёба, работа, социальные сети, бесконечный поток информации и постоянные дедлайны. Всё это может приводить к стрессу, эмоциональному истощению и выгоранию.

Мы решили создать пространство, в котором можно сделать небольшую паузу, переключить внимание и позаботиться о своём эмоциональном состоянии.

**PurrTok — это не просто бот, а маленький цифровой уголок спокойствия.**

## ✨ Основные возможности

### 🧠 1. Кот-поддержка

Виртуальный ИИ-помощник, который помогает пользователю разобраться в своих эмоциях и получить эмоциональную поддержку.

Возможности:
- Выбор текущего настроения: грусть, тревога, усталость, радость и другие состояния.
- Свободное общение с ИИ-агентом.
- Поддерживающий диалог и рекомендации по эмоциональному благополучию.
- Возможность рассказать о переживаниях своими словами, не ограничиваясь готовыми вариантами.
- Отправка кошачьего мурлыканья для создания расслабляющей атмосферы.

Котик специализируется на психологической и эмоциональной поддержке. Он не заменяет профессионального психолога или врача, но может стать первым шагом к заботе о себе.

### 🎮 2. Виртуальный Тыгыдык

Интерактивная мини-игра, позволяющая переключить внимание, отвлечься от рутины и выплеснуть накопившиеся эмоции в игровом процессе.

Особенности:
- Интерактивная игровая механика.
- Система комбо и множителей очков с таймером.
- Бонусные рыбки и дополнительные игровые эффекты.
- Динамические анимации и визуальные взаимодействия.
- Генерация звуковых эффектов непосредственно во время игры.

### 😺 3. Мемные карточки-статусы

Игровые результаты и настроение пользователя становятся поводом для создания забавных карточек, которыми можно поделиться с друзьями и коллегами.

Это добавляет проекту социальный элемент и позволяет распространять позитивное настроение за пределами бота.

## ⚙️ Техническая реализация

Одной из особенностей проекта стало сочетание Telegram-бота, ИИ-агента и собственного веб-приложения.

### Telegram и WebApp
- Интеграция с Telegram Bot API через платформу LEADTEX.
- Запуск интерактивного веб-приложения непосредственно внутри Telegram.
- Адаптация интерфейса под мобильные устройства.
- Взаимодействие между ботом и веб-приложением.

### Игровой JavaScript-движок
- Расчёт расположения игровых объектов.
- Система комбо-множителей с ограничением по времени.
- Расчёт траекторий бонусных объектов.
- Использование Web Animations API для управления анимациями.

### Динамический звуковой дизайн
- Генерация звуковых эффектов средствами Web Audio API.
- Использование осцилляторов для создания звуков взаимодействия с различными материалами.
- Отсутствие необходимости хранить отдельный аудиофайл для каждого эффекта.

### CSS и визуальная составляющая
- Псевдотрёхмерная сцена на основе CSS Perspective.
- Анимированные элементы игрового окружения.
- Использование CSS Keyframes.
- Адаптивная вёрстка с помощью CSS-функции `clamp()`.
- Поддержка `prefers-reduced-motion` для пользователей, предпочитающих уменьшенное количество анимаций.

## 🤖 Использование искусственного интеллекта

Искусственный интеллект стал одним из инструментов разработки PurrTok и помог ускорить реализацию технически сложных компонентов.

В процессе разработки ИИ использовался для:
- Создания и оптимизации CSS-анимаций.
- Разработки отдельных элементов игровой логики.
- Подготовки адаптивных стилей и медиа-запросов.
- Поиска ошибок и помощи при отладке.
- Реализации отдельных технических решений.

При этом **ИИ выступал в роли интеллектуального ассистента, а не самостоятельного разработчика**.

Архитектура проекта, выбор технических решений, игровая логика, интеграция компонентов и итоговая проверка кода оставались под контролем участников команды.

Такой подход позволил сократить время на рутинные задачи и сосредоточиться на качестве и функциональности продукта.

## 🎯 Целевая аудитория

PurrTok ориентирован прежде всего на людей, которые много времени проводят за компьютером или смартфоном и сталкиваются с высокой информационной и эмоциональной нагрузкой.

Основные группы пользователей:
- **Студенты** — учёба, экзамены, дедлайны и постоянная нагрузка.
- **Удалённые сотрудники** — высокая занятость и недостаток переключения между работой и отдыхом.
- **IT-специалисты** — длительная работа за экраном, сложные задачи и профессиональное выгорание.
- **Активные пользователи социальных сетей** — информационная перегрузка и думскроллинг.
