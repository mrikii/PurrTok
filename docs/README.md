# PurrTok — «Тыгыдык» (игра без дополнительных страниц)

Версия **3.2.0**. Запускается **сразу игровой экран**. Нет стартовой страницы, чата и навигации между разделами.

## Запуск

1. Распакуйте архив.
2. Откройте `PurrTok/index.html` в браузере.
3. Вы сразу увидите игру «Тыгыдык». Нажмите **«Начать шалить»** для старта 60-секундного раунда. Этот клик необходим, в частности, чтобы мобильный браузер разрешил воспроизведение звуков.

Для публикации разместите содержимое папки `PurrTok` на HTTPS-хостинге. Для Telegram Mini App укажите HTTPS-адрес `index.html` в настройках Telegram-бота.

## Что сохранено

- Разрушение предметов: трещины, 12 фрагментов, частицы
- Расположение предметов на столе и задних полках
- Две рыбки с разными траекториями и бонусами
- Счёт, комбо, таймер 60 секунд, рекорды и итоговый экран
- Звуки ударов по материалам; кошачьих звуков при разбивании нет
- Адаптивный дизайн, работа в мобильном браузере и Telegram WebApp

Всё работает локально, без платных API. Локальные рекорды сохраняются в хранилище браузера.
