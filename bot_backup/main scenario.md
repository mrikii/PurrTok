# 🏠 Главный сценарий PurrTok

## Описание

Главный сценарий является центральной точкой навигации Telegram-бота PurrTok. После запуска пользователь попадает в главное меню, откуда может перейти к одной из трёх основных функций проекта: психологической поддержке, интерактивной игре или получению случайной мемной карточки.

## Структура сценария

### 1. Старт

При первом взаимодействии с ботом запускается стартовый блок, который переводит пользователя в главное меню.

### 2. Главное меню

Пользователю предлагается три основных варианта взаимодействия:

#### 🧠 ИИ Кот-Психолог
Переводит пользователя в отдельный сценарий психологической и эмоциональной поддержки.

Возможности:
- Выбор текущего эмоционального состояния.
- Свободное общение с ИИ-агентом.
- Получение рекомендаций по улучшению эмоционального состояния.
- Возможность рассказать о своих переживаниях в свободной форме.

#### 🎮 Виртуальный Тыгыдык
Открывает игровое веб-приложение (Telegram Mini App) непосредственно внутри Telegram.

Игра позволяет пользователю отвлечься от повседневных забот, переключить внимание и получить положительные эмоции благодаря интерактивному игровому процессу.

#### 😺 Статус дня
Запускает механизм случайной выдачи мемной карточки.

Для реализации случайного выбора используется блок A/B-тестирования LEADTEX, который распределяет пользователя между несколькими заранее подготовленными цепочками сообщений.

Каждая цепочка содержит уникальный вариант:
- Забавного текста.
- Мемного статуса дня.

Таким образом, пользователь получает один из случайных вариантов карточки. После её просмотра предусмотрен переход обратно в главное меню.

## Логика переходов

| Элемент | Действие |
|---|---|
| Старт | Переход в главное меню |
| ИИ Кот-Психолог | Переход в сценарий психологической поддержки |
| Виртуальный Тыгыдык | Открытие Telegram Mini App |
| Статус дня | Запуск случайного выбора мемной карточки |
| Цепочки карточек | Выдача выбранного варианта пользователю |
| Перейти в меню | Возврат к главному экрану |

## Техническая реализация

Сценарий построен с использованием визуального конструктора LEADTEX.

Основные механизмы:
- **Цепочки сообщений** — отображение главного меню и взаимодействие с пользователем.
- **Переходы между сценариями** — разделение функциональности бота на независимые модули.
- **Telegram WebApp** — запуск игрового приложения внутри Telegram.
- **A/B-тестирование** — случайное распределение пользователей между вариантами мемных карточек.

## Назначение сценария

Главный сценарий обеспечивает удобную навигацию между основными возможностями PurrTok и позволяет пользователю самостоятельно выбрать подходящий способ психологической разгрузки: поговорить с виртуальным помощником, отвлечься с помощью игры или поднять себе настроение случайной мемной карточкой.
